# Photos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tải ảnh lên, xem, chú thích, sắp xếp, gỡ ảnh của địa điểm, người, món đồ; đặt ảnh bìa và ảnh đại diện.

**Architecture:** `media-service` có kho file trên đĩa sau interface `FileStorage`, bộ đọc ảnh (`ImageInspector`: giải mã thật, xoay theo EXIF, tạo ảnh thu nhỏ 480 px JPEG), dịch vụ tải lên có chống trùng theo SHA-256, API gắn ảnh và API trả nội dung (đường dẫn mang id không gian vì `<img>` không gửi header). Frontend có feature lá `features/media` (`PhotosTab`); `app/` ghép tab Ảnh vào trang địa điểm và người, trang món đồ nhập thẳng; ảnh bìa và ảnh đại diện ghi bằng lệnh sửa sẵn có của registry.

**Tech Stack:** Spring Boot 4, JdbcClient, Flyway (không đổi schema media), ImageIO + TwelveMonkeys `imageio-webp`, `imageio-jpeg`, `imageio-metadata` (bản 3.12.0); React 19, TanStack Query, openapi-fetch, shadcn `carousel`, `aspect-ratio`, `dialog`, `dropdown-menu`; msw.

**Spec:** `docs/superpowers/specs/2026-11-25-photos-design.md`.

## Global Constraints

- Lệnh như `2026-11-25-capacity-and-vacancies.md`. Maven lần đầu chạy **không** `-o` để tải TwelveMonkeys. IT của media: `-pl media-service -am verify -Dit.test=<Tên>IT -Dtest=NoSuchTest -Dsurefire.failIfNoSpecifiedTests=false -Dfailsafe.failIfNoSpecifiedTests=false`.
- Làm trên nhánh `batch-7-photos`; mỗi task một commit; không commit `platform-common/pom.xml`, `pom.xml`.
- Chỉ nhận `image/jpeg`, `image/png`, `image/webp`; tối đa 10 MB (10 485 760 byte); nội dung phải giải mã được và đúng định dạng khai báo (M1).
- Ảnh thu nhỏ: cạnh dài tối đa 480 px, không phóng to, JPEG chất lượng 0.85, nền trắng (M3). `width`, `height` theo chiều hiển thị sau EXIF (M2).
- Tối đa 100 ảnh đang hiện mỗi bản ghi (M5); PENDING quá 1 giờ bị dọn, mỗi giờ một lần (M9).
- Khoá kho: `workspaces/<ws>/files/<id>` và `workspaces/<ws>/files/<id>/thumb`. Gốc kho `media.storage.root`, mặc định `data/media`; `data/` vào `.gitignore`.
- Nội dung ảnh: `GET /workspaces/{ws}/files/{id}` và `/thumbnail`, header `Cache-Control: private, max-age=31536000, immutable` và `X-Content-Type-Options: nosniff`.
- Media không nhập gì của registry (luật kiến trúc `noOtherServices`). `features/media` không nhập feature nào khác.
- Chữ mới đúng nguyên văn như spec mục 4.3.

## Review Focus

1. Ảnh JPEG chụp dọc trên điện thoại (EXIF Orientation 6): `width` < `height`, ảnh thu nhỏ đứng. Test: `exifRotationIsApplied` (Task 2), `portraitPhoneShotIsStoredUpright` (Task 3).
