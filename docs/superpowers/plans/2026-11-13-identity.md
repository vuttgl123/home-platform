# Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bước 5 của logic nghiệp vụ: người dùng và không gian trong `identity-service`, đủ để biết ai sở hữu không gian nào khi chưa có đăng nhập.

**Architecture:** Hai package `com.home_platform.identity.user` và `...workspace`, ba tầng. Bảng `idn_` có khoá `id` (không có `workspace_id`), nên repository viết SQL tay với `EntityMetadata` của `platform-common` thay vì kế thừa `WorkspaceRepository`; không sửa `platform-common`. Người gọi lấy từ `UserContext` (header `X-User-Id`).

**Spec:** `docs/superpowers/specs/2026-11-13-business-rules-design.md` mục 3, 4.

## Global Constraints

- Ràng buộc chung của các kế hoạch registry: request và response riêng, MapStruct, chú thích tiếng Việt, thông báo lỗi tiếng Anh, cắt khoảng trắng, mã lỗi 400/404/409, test `*IT` trên UAT và rollback, commit mỗi task, push ở cuối.
- `id` sinh bằng `IdGenerator`; thời điểm lấy từ `Clock`, cắt tới mili giây.
- Không gian mà người gọi không phải thành viên được coi là không tồn tại (404). Vai trò (OWNER, EDITOR, VIEWER) có trong dữ liệu nhưng chưa được kiểm tra (spec mục 2).
- Test dùng email đuôi `@example.invalid` và rollback; không để lại người dùng nào.

## Review Focus

1. Email khác nhau chỉ ở chữ hoa (`A@Example.invalid` và `a@example.invalid`) là trùng. Test: `duplicateEmailIsAConflict` (Task 1).
2. Người dùng không tồn tại hoặc đã bị vô hiệu không tạo được không gian. Test: `unknownOrDisabledUserCannotCreate` (Task 2).
3. Người không phải thành viên không xem, không đổi tên được không gian của người khác. Test: `outsidersCannotSeeOrRename` (Task 2).
4. Phân trang "các không gian của tôi" khi trùng tên không sót, không lặp. Test: `myWorkspacesAreSortedByNameAndPaged` (Task 2).

### Task 1: Người dùng

**Files:** `identity-service/src/main/java/com/home_platform/identity/user/{UserStatus,User,UserRepository,UserService,UserController,UserMapper,UserCreateRequest,UserRenameRequest,UserResponse}.java`; test `identity-service/src/test/java/com/home_platform/identity/{IdentityIT,user/UserIT}.java`.

```java
public enum UserStatus { ACTIVE, DISABLED }
@With public record User(long id, String email, String displayName, UserStatus status, Instant createdAt, Instant updatedAt) {}
public record UserCreateRequest(@NotBlank @Email @Size(max = 255) String email, @NotBlank @Size(max = 150) String displayName) {}  // email chữ thường
public record UserRenameRequest(@NotBlank @Size(max = 150) String displayName) {}

@Service public class UserService {
	public User get(long id)                                   // NotFoundException.of("User", id)
	public User create(UserCreateRequest request)              // trùng email: ConflictException("User with email <email> already exists")
	public User rename(UserContext ctx, UserRenameRequest request)
}
```

HTTP: `POST /users` 201 (không cần header); `GET /users/me`, `PUT /users/me` (cần `X-User-Id`).

Test (`UserIT`): `createsAUserWithLowercaseEmail`; `duplicateEmailIsAConflict`; `invalidEmailOrBlankNameIs400`; `meReturnsTheCaller`; `unknownCallerIs404`; `renameChangesTheDisplayName`.

### Task 2: Không gian

**Files:** `identity-service/src/main/java/com/home_platform/identity/workspace/{WorkspaceStatus,MemberRole,Workspace,MemberWorkspace,WorkspaceRepository,WorkspaceService,WorkspaceController,WorkspaceMapper,WorkspaceRequest,WorkspaceResponse}.java`; test `.../workspace/WorkspaceIT.java`.

```java
public enum WorkspaceStatus { ACTIVE, SUSPENDED }
public enum MemberRole { OWNER, EDITOR, VIEWER }
@With public record Workspace(long id, long ownerUserId, String name, WorkspaceStatus status, Instant createdAt, Instant updatedAt) {}
public record MemberWorkspace(Workspace workspace, MemberRole role) {}

@Service public class WorkspaceService {
	public MemberWorkspace create(UserContext ctx, WorkspaceRequest request)   // người gọi phải tồn tại và ACTIVE
	public MemberWorkspace get(UserContext ctx, long id)                       // không phải thành viên: NotFoundException.of("Workspace", id)
	public CursorPage<MemberWorkspace> mine(UserContext ctx, CursorRequest page)  // theo tên rồi id; cursor [name, id]
	public MemberWorkspace rename(UserContext ctx, long id, WorkspaceRequest request)
}
```

  - Tạo: `idn_workspace` và dòng `idn_workspace_member` vai trò OWNER trong một transaction. Người dùng DISABLED: `ConflictException("User <id> is disabled")`.
  - Response: `id, name, status, ownerUserId, role, createdAt, updatedAt`.
  - HTTP: `POST /workspaces` 201, `GET /workspaces`, `GET /workspaces/{id}`, `PUT /workspaces/{id}`.

Test (`WorkspaceIT`): `createMakesTheCallerOwner`; `unknownOrDisabledUserCannotCreate`; `myWorkspacesAreSortedByNameAndPaged` (5 không gian, hai cái trùng tên, limit 2: đủ 5, không trùng, đúng thứ tự); `outsidersCannotSeeOrRename`; `renameChangesTheName`; `blankNameIs400`.
